# pdf-text-extract Frontend

React app for the pdf-text-extract project.

## Tech Stack

- React 19
- React Router 7
- TypeScript
- Vite
- Tailwind CSS

## Scripts

- `pnpm dev` – Start dev server
- `pnpm build` – Build for production
- `pnpm lint` – Lint code
- `pnpm format` – Format code

## Development

1. Install dependencies:
   ```sh
   pnpm install
   ```
2. Start dev server:
   ```sh
   pnpm dev
   ```

## Directory Structure

- `app/` – Main app code
- `public/` – Static assets
