# pdf-text-extract

Monorepo for PDF text extraction and processing, containing both backend (NestJS) and frontend (React) apps.

## Structure

- `backend/` – NestJS API for PDF processing
- `frontend/` – React app for user interface

## Getting Started

1. Install dependencies (from root):
   ```sh
   pnpm install
   ```
2. Run all apps in development mode:
   ```sh
   pnpm dev
   ```

## Scripts

- `pnpm dev` – Start all apps in dev mode
- `pnpm build` – Build all apps
- `pnpm lint` – Lint all packages
- `pnpm test` – Run all tests

## Requirements

- Node.js 20+
- pnpm 10+
