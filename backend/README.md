# pdf-text-extract Backend

NestJS API for the pdf-text-extract project.

## Tech Stack

- NestJS 11
- TypeScript

## Scripts

- `pnpm start` – Start server
- `pnpm dev` – Start in watch mode
- `pnpm build` – Build for production
- `pnpm lint` – Lint code
- `pnpm test` – Run tests

## Development

1. Install dependencies:
   ```sh
   pnpm install
   ```
2. Start dev server:
   ```sh
   pnpm dev
   ```

## Directory Structure

- `src/` – Source code
- `test/` – Tests
